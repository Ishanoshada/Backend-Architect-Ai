

# Backend Architect AI 🏗️

Generate complete backend architecture, database schemas, and API routes from your application idea using AI. This tool helps developers jumpstart their backend development by providing a comprehensive plan including database models, API endpoints, security considerations, and more.

## Features 🚀

- **Architecture Planning**: Get AI recommendations for the best architecture pattern based on your needs
- **Database Design**: Auto-generated database schemas with proper relationships and data types
- **API Design**: Comprehensive RESTful API routes with example requests/responses
- **Tech Stack Support**: Framework-specific code generation for popular stacks like Node.js, Python, Go, and more
- **Security & Scalability**: Built-in security recommendations and scalability considerations
- **UML Diagrams**: Visual representation of your database models and relationships
- **Docker Setup**: Ready-to-use docker-compose files for local development
- **Deployment Plans**: Platform recommendations and Dockerfile generation

## Getting Started 🛠️

### Prerequisites

- Node.js (v16 or higher)
- A Google Gemini API key

### Installation

1. Clone the repository:
```bash
git clone https://github.com/ishanoshada/Backend-Architect-Ai.git
cd Backend-Architect-Ai
```

2. Install dependencies:
```bash
npm install
```

3. Create a `.env.local` file in the root directory:
```bash
GEMINI_API_KEY=your_api_key_here
```

4. Start the development server:
```bash
npm run dev
```

5. Open [http://localhost:5173](http://localhost:5173) in your browser

## Usage 📝

1. Enter your application idea in the text area
2. (Optional) Specify key features you want to prioritize
3. (Optional) Select your preferred:
   - Technology Stack
   - Architecture Pattern
   - Database Type
   - Application Complexity
4. Click "Generate Plan" to create your backend architecture
